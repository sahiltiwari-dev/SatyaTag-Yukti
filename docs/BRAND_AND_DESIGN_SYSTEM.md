# SATYATAG Brand and Design System

## 1. Brand Direction
SATYATAG is a rigorous Indian Legal Metrology inspection and compliance platform. The brand identity emphasizes trust, precision, neutrality, and regulatory authority.

- **Primary Identity**: Deep Regulatory Navy (`#0F172A` / `#1E293B`)
- **Action / Accent**: GovBlue (`#2563EB` / `#3B82F6`)
- **Semantic Status**:
  - Success: Emerald (`#059669`)
  - Warning: Amber (`#D97706`)
  - Error / Violation: Rose / Red (`#E11D48`)
- **Surfaces**:
  - Light: Pure white (`#FFFFFF`) with off-white slate backgrounds (`#F8FAFC`).
  - Dark: Deep charcoal (`#0B0F19`) with slate-900 panels (`#111827`).

## 2. Typography
- **Font Family**: Inter, system-ui, -apple-system, sans-serif.
- **Hierarchy**:
  - Page Title: 24px / 32px bold
  - Section Heading: 18px / 24px semi-bold
  - Body: 14px / 20px regular
  - Caption / Metadata: 12px / 16px medium

## 3. Shared Component System
- **Buttons**: Primary, secondary, outline, danger variants with accessible focus rings.
- **Cards**: Clean borders (`border-slate-200 dark:border-slate-800`), subtle shadows, rounded-card.
- **Badges**: Status-aware semantic badges for PASS, FAIL, NEEDS_REVIEW, and IN_PROGRESS.
- **Modals**: Centered backdrop-blur dialogs with escape-key and click-outside dismissal.
